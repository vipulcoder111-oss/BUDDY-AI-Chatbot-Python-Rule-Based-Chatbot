# BUDDY-AI-Chatbot-Python-Rule-Based-Chatbot
BUDDY AI Chatbot is a simple Python-based rule chatbot that responds to user questions using predefined keywords and responses. It demonstrates functions, dictionaries, loops, conditions, and user input in an interactive way. 🤖🐍

# 🤖 BUDDY AI Chatbot

## 📌 About the Project

BUDDY AI is a simple rule-based chatbot developed using Python.<br>
It interacts with users through predefined responses and provides a basic conversational experience.

<br>

## ✨ Features

- 💬 Responds to user messages
- 👋 Handles basic greetings
- 🤖 Provides predefined responses
- 🚪 Allows users to exit the chatbot
- 🐍 Simple and beginner-friendly Python project

<br>

## 🛠️ Technologies Used

- 🐍 Python
